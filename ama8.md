1\. What is `manage.py`?

`manage.py` is a command-line utility in Django used to run the development server, create migrations, apply migrations, and manage the project.

2\. What is atomicity?

Atomicity is an ACID property that ensures a transaction is completed entirely or not at all. If any part fails, the entire transaction is rolled back.

3\. What is durability in ACID?

Durability ensures that once a transaction is committed, its changes remain permanently stored, even if the system crashes.

4\. What is `git cherry-pick`?

`git cherry-pick` is a Git command used to apply a specific commit from one branch to another branch without merging the entire branch.

5\. How do you count the number of words in a file?

In Linux, we use the `wc -w filename.txt` command to count the number of words in a file.

6\. How do we call an API in JavaScript?

We can call an API in JavaScript using the `fetch()` method or libraries like Axios. The `fetch()` method is commonly used to send HTTP requests and handle responses.

7\. When do we use `forEach()`, `map()`, and `filter()`?

Answer:

- `forEach()` is used to perform an action on each array element.
- `map()` is used to create a new array by transforming each element.
- `filter()` is used to create a new array containing elements that satisfy a condition.

8\. What is a primary key?

A primary key is a column or set of columns that uniquely identifies each record in a database table. It cannot contain duplicate or `NULL` values.

9\. What is `include()` in Django?

`include()` is used in Django's URL configuration to include URL patterns from another app's `urls.py` file into the main project's URL configuration.

10\. Explain Elasticsearch.

Elasticsearch is a distributed search and analytics engine that stores data in an index and allows us to search data quickly. In Django, it can be used to implement features such as full-text search and search-as-you-type.
