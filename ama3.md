## 1. What is `git reset`?

`git reset` is used to **move the current branch to an earlier commit**.



## 2. Is Python a compiled or interpreted language?

Python is generally considered an **interpreted language**, where the Python interpreter executes the code.



## 3. Which clause is used to sort data in SQL?

`ORDER BY` is used to **sort data in SQL**.



## 4. What is the difference between `sort()` and `sorted()`?

* `sort()` **changes the original list**.
* `sorted()` **returns a new sorted list** without changing the original list.



## 5. How do you exit from PostgreSQL (`psql`)?

Use **`\q`** to exit the PostgreSQL `psql` terminal.


## 6. What is `git pull`?

`git pull` is used to **get the latest changes from a remote Git repository into the local repository**.



## 7. What is the difference between `position: fixed` and `position: sticky`?

* `fixed` keeps an element **fixed on the screen**.
* `sticky` keeps an element **in its normal position until it reaches a specific scroll position, then it sticks**.



## 8. What are mutable and immutable collections?

* **Mutable** means the collection **can be changed after creation**.
* **Immutable** means the collection **cannot be changed after creation**.

### Mutable
- List
- Dictionary
- Set

### Immutable
- Tuple
- String



## 9. Why do we use absolute and relative positioning?

* **Relative** is used to **position an element relative to its normal position** and can provide a reference point for an absolute child.
* **Absolute** is used to **position an element relative to its nearest positioned ancestor**.



## 10. Which command is used to list branches in Git?

`git branch` is used to **list local Git branches**.



## 11. What is `zip()` in Python?

`zip()` is used to **combine corresponding elements from two or more iterables**.



## 12. What is specificity in CSS?

**CSS specificity** determines **which CSS rule gets higher priority when multiple rules apply to the same element**.
