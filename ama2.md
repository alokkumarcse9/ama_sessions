# Alok Kumar — AMA Answers

## 1. What is Flexbox in CSS?

Flexbox is a CSS layout system used to arrange elements easily in a row or column.



## 2. What is the difference between a Primary Key and a Foreign Key?

A Primary Key uniquely identifies each row in a table, while a Foreign Key connects one table with another table.


## 3. What is CSS Specificity?

CSS specificity decides which CSS rule will be applied when multiple CSS rules target the same element.


## 4. Which Git command is used to list commits?

`git log` is used to list and view the commit history.


## 5. What is the difference between Relative and Absolute in CSS Positions?

`position: relative` keeps an element in the normal document flow and moves it relative to its original position.

`position: absolute` removes an element from the normal document flow and places it at an exact position relative to its nearest positioned parent.



## 6. What is the difference between HTML and CSS?

HTML creates the structure and content of a webpage, while CSS controls its style and layout.


## 7. Why do we use Abstract Classes in OOPs?

An abstract class is used to create a common structure that child classes must follow.


## 8. What is the difference between `remove()`, `pop()`, and `del` in Python?

`remove()` deletes an item by value, `pop()` removes an item by index and returns it, and `del` deletes an item, a range of items, or an object.


## 9. What is Encapsulation in OOPs?

Encapsulation means keeping data and methods together inside a class and controlling access to the data.


## 10. What is the difference between `git log` and `git reflog`?

`git log` shows the commit history, while `git reflog` shows the history of changes to Git references such as HEAD.


## 11. Why do we prefer CSS Grid over Flexbox?

We use CSS Grid when we need to control both rows and columns, while Flexbox is mainly used to arrange elements in one direction.
