### 1. What is a platform?

A platform is a software or environment where users can perform tasks, build applications, or use different tools and services.

### 2. How do hooks indicate that a task is complete?

Hooks are scripts or functions that run at specific points in a workflow. They can check the task status and indicate completion when certain conditions are met.

### 3. What are `PreToolUse` and `PostToolUse` hooks?

- PreToolUse: Runs before a tool is used. It can check or validate the action.
- PostToolUse: Runs after a tool has been used. It can log results, validate output, or perform follow-up actions.

### 4. What is temperature in AI?

Temperature is a setting that controls the randomness of AI responses. A low temperature produces more predictable answers, while a high temperature produces more varied and creative answers.

### 5. What is the full form of MCP?

MCP stands for Model Context Protocol. It is a standard that allows AI applications to connect with external tools, data sources, and services.

### 6. What is Plan Mode?

Plan Mode is a mode in which an AI coding assistant analyzes a task and creates a step-by-step plan before making code changes. It helps users review the approach before implementation.

### 7. What is Claude for Microsoft 365?

Claude for Microsoft 365 integrates AI capabilities with Microsoft 365 applications and workflows, helping users work with documents, emails, presentations, and other business tasks, depending on the available integration and permissions.
