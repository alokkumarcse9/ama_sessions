# AMA Questions and Answers

## 1. What is a Full Join?

A Full Join returns **all records from both tables**. If there is no matching record, it shows `NULL` for that side.

## 2. What is a Pseudo Column in SQL?

A pseudo column is like a **hidden or virtual column** provided automatically by the database. It looks like a normal column and can be used in queries, but it is **not actually stored in the table**, like `ROWNUM` in Oracle.

## 3. What is `self` in Python?

`self` refers to the **current object of a class**. We use it to access the object's variables and methods.

## 4. What is Inheritance in Python?

Inheritance means a **child class can inherit the properties and methods of a parent class**. It is basically a **parent-child relationship between classes**.

## 5. How do you sort data in SQL, and which clause is used?

We use the **`ORDER BY` clause** to sort data. By default, it sorts in ascending order, and we can use `DESC` for descending order.

## 6. What is the `find` command?

`find` is a Linux command used to **search for files and directories** based on conditions like name, type, or size.

## 7. What is SRP?

SRP stands for Single Responsibility Principle. It means a class should have only one responsibility or one main reason to change.

## 8. What is the difference between `UNION` and `UNION ALL`?

`UNION` combines results and **removes duplicate rows**, while `UNION ALL` combines results **without removing duplicates**.

## 9. What is the `grep` command?

`grep` is a Linux command used to **search for a specific word or pattern inside files or command output**.

## 10. What is the difference between `[]` and `get()` in a dictionary?

`dict[key]` gives an error if the key doesn't exist, while `dict.get(key)` **returns `None` or a default value** instead of giving an error.

## 11. What happens after running `git init`?

`git init` creates a **new Git repository** in the current folder by creating a hidden `.git` directory.

## 12. Who developed Python?

Python was developed by **Guido van Rossum**. He started developing it in the late 1980s, and the first public release came in 1991.

## 13. What is the difference between a List and a Tuple?

A **list is mutable**, so we can change its elements. A **tuple is immutable**, so once created, its elements cannot be changed.
